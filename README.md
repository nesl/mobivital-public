# MobiVital
Repository containing code, checkpoint, and link to the dataset for paper "MobiVital: Self-supervised Quality Estimation for UWB-based Contactless Respiration Monitoring"

## Dataset
Public Link to the Dataset: https://doi.org/10.5281/zenodo.15022885
Dataset Github repo: https://github.com/nesl/MobiVital-dataset
Publication: https://dl.acm.org/doi/abs/10.1145/3722570.3726878
Tech Report: https://arxiv.org/pdf/2503.11064

## Requirements
The code is tested using Python 3.10.14. Using a virtual environment is recommended.
See requirements.txt for package requirements.

## Dataset Preparation and MobiVital Training

### Dataset Preparation
After cloning this respository and downloading the dataset, place the dataset inslide the working directory:
```text  
mobivital-public/  
├── README.md  
├── ...
└── dataset/  
    └── mobivital/  
        └── tripod/  
		        └── EXP_NAME.csv
		        └── ...
```

Python command to prepare the dataset for MobiVital model training:

    python dataset_preparation/prep_breath_final.py

### Training
Run python script in the `mobivital-public/` directory to training the model:

    python -m training.autoreg_training

The default model hyperparameter comes from .`/checkpoints/optimal_params.json`. By default, the trained model is also saved to ./checkpoints. Please read the argparse section of `./training/autoreg_training.py` if you would like to customize the model training.
**Warning:** a pretrained checkpoint is available. Running the training script using the default parameters will override the checkpoint. So back the default checkpoint up if necessary.

## Evaluations

### Evaluating MobiVital

Once the checkpoint is ready, run python script in the mobivital-public/ directory to evaluate the model on the testing uses G, H, I, and J:

    python -m inference.mobivital_gen

If you have adjusted the correlation threashold during the training (e.g., to 0.7), you need to add additional parameters:

     python -m inference.mobivital_gen -c 0.7

This script will produce a .txt file in `./inference/methods`. Each entry of the txt shows what kind of processing Mobivital suggest to apply on each dataset entry. For example:

> 231005_userJ_tripod_01_6.csv,29,abs,0

This line suggests, for "231005_userJ_tripod_01_6.csv", we should take distance bin 29, take the amplitude (abs) of the complex number, and do not need to invert the resulting time series (1 means inversion required). 

The `mobivital_gen.py` script also provides an average score of the current model, by calcalating the average correlation coefficient between the timeseries selected by MobiVital and the ground truth breath waveform, which is reported in the paper.

### Running Baselines (Optional)
We also provide MATLAB code script that generate similar .txt files for baseline methods. Simply open MATLAB, navigate to `./baselines`, and pick the method you would like to try, for example, `main_std_abs.m` select UWB-breath waveform using the stardard deviation of the amplitude of each bin. Please refer to the paper for details.

### Detailed Analysis
Finally, you can perform detailed analysis 

    python -m inference.evaluate -m YOUR_METHOD.txt

This script (`./inference./evaluate.py)` will print the average score score of your method (e.g., MobiVital).

Again, the score is defined as `corr(ground truth breath waveform, selected UWB breath waveform)`. The script will also save the score on each individual entry of the testing dataset to `./inference/methods/scores.csv`. 

For the intermediate .txt file generated by MATLAB, add --mat to the command to account for the fact that MATLAB index matrices from 1 instead of 0.

    python -m inference.evaluate -m YOUR_METHOD.txt --mat
